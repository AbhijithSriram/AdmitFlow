# Project rules for AI coding assistants

- Do not add `Co-Authored-By:` trailers or any other AI/assistant attribution
  (for example "Generated with ...") to commit messages or pull request descriptions.
- Do not modify `.env`, `.env.template` secrets, or commit credentials. `.env` is gitignored.
- Stay inside the file list for your assigned slice in `IMPLEMENTATION_PLAN.md`; shared backbone
  files (`backend/app/__init__.py`, `config.py`, `extensions.py`, `frontend/src/App.jsx`,
  `frontend/src/api/client.js`, `backend/migrations/schema.sql`) need team agreement first.
